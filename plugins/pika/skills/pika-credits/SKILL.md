name: pika-credits
description: Use when a Pika tool says the user is out of credits or doesn't have enough for a run, or the user asks how to get more Pika credits.
---

# Credits

1. Say in one line what they have and what the run needs, from the quote or error.
2. Link them to https://pika.art/pricing, where they can see the plans and credit packs and add credits to their Pika account. If you have `show_billing`, call it as well.
3. Offer a cheaper version where one exists: shorter, lower resolution, a lighter model, or fewer takes.
4. Don't run it again until they say they've added credits; then quote it again with the same input and a fresh `request_id`.
